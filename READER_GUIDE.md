# TBH Reader Guide

## Read Only

Read chapters in order. No setup is required.

## Build With An Agent

Open this repo or your build repo in a coding agent. Ask it to follow `AGENTS.md`, then set up `.tbh/`, choose your language, build chapters, validate, and review.

For the smoothest guided experience, ask the agent to explain `tbhbooks-agent-kit`, show the pinned GitHub release URL, and ask before installing it into `.tbh/tbhbooks-agent-kit/`.

## Convert Later

If you start as a casual reader, you can switch to build-along mode later by asking your agent to follow `AGENTS.md`.
