# TBH Prompt Gallery

Use these prompts with any coding agent after opening this book repo or your build repo.

## Setup

> Set up TBH for this book. Use the language I choose and create local `.tbh/` state.

## Agent Kit

> Explain the value of `tbhbooks-agent-kit`, show me the pinned version and GitHub release URL, then ask before downloading it into `.tbh/tbhbooks-agent-kit/`.

## Build

> Start the current chapter and give me a focused build brief.

> Start chapter 3 and show the interfaces I need to implement.

## Validate

> Validate my current chapter implementation against the spec.

## Hint

> Give me a small hint for the current chapter without solving it.

## Review

> Review my implementation against the chapter spec and validation tests.

## Explain

> Explain this chapter concept in the context of my code.

## Live Reference

> Compare this chapter's approach with current real-world systems and separate book facts from external references.
